📖 使用說明

① 設定文書背景 選擇文書種類並填入關鍵背景資訊，這將成為 AI 生成的核心依據。
② 視覺畫布排版 點擊元件按鈕新增區塊，用拖曳安排文書結構順序。雙擊任一區塊可修改內容、顏色或刪除。啟用連線模式後，依序點擊兩個區塊即可建立箭頭連線，指示文件流程。
③ 編譯並輸出 Prompt 點擊「編譯生成 Prompt」，系統依畫布垂直排序與連線關係，自動組裝完整 AI 提示詞。
🆕 截圖協作板 點擊「截圖至協作板」擷取畫布結構，生成可分享連結，供團隊成員查看你的文書架構設計。
🆕 Prompt 雲端筆記 生成 Prompt 後，可儲存至雲端筆記庫，並取得專屬連結。方便日後調用或分享給同事。
🆕 會議錄音記事本 點擊頂部「🎙 會議錄音」或左側錄音面板開始錄製。支援 Web Speech API 語音即時轉文字（Chrome/Edge），錄音結束後可用「✨ AI 整理」自動生成結構化會議記錄，再一鍵「☁ 上傳至雲端記事本」取得分享連結。
